# Labeling rules (analytical state) used to build the fine-tuning answers

All answers are generated by deterministic templates in `generate_dataset.py`. Every number is copied verbatim
from a tool output (verified by `harness/validate.py`: 0 violations across 1,410 conversations).

| Scenario | Rule (first match wins) | State |
|---|---|---|
| S1 sector catch-up | weakest stock lag smaller than threshold (5 pp) | WATCH |
| | sector not strong (median ≤ 0 or ≤ XU100) | WATCH |
| | fewer than 10 non-overlapping 20-day events | INVESTIGATE |
| | 20d hit rate ≥ 55%, mean rel. return after cost > 0, and Supertrend bullish or close > KAMA | POTENTIAL_CATCH_UP_CANDIDATE |
| | 20d hit rate < 45% | REJECT_SIGNAL |
| | otherwise | WATCH |
| | candidate but fundamentals not loaded (fundamentals and macro are always checked to separate structural from temporary lag) | downgraded to INVESTIGATE |
| S2 weekday | in-sample p ≤ 0.0016 (Bonferroni, 32 patterns) and ≥ 10 occurrences and OOS tradable mean after cost > 0 and OOS p < 0.05 | WATCH |
| | in-sample significant but not confirmed OOS | INVESTIGATE |
| | not significant after multiple-testing correction | REJECT_SIGNAL |
| S2 multi-day | < 10 complete events | INVESTIGATE |
| | up rate > unconditional and mean after cost > 0 | WATCH |
| | otherwise | REJECT_SIGNAL |
| S3 reversal | < 10 events with complete forward window | INVESTIGATE |
| | success ≥ 60% and an event in the last 10 trading days | TECHNICAL_REVERSAL_CANDIDATE |
| | success ≥ 60%, no recent event | WATCH |
| | success < 50% | REJECT_SIGNAL |
| | otherwise | WATCH |
| S4 fundamentals | no disclosed quarters in data | INVESTIGATE |
| | < 4 quarters with complete 20-day window | INVESTIGATE |
| | latest disclosed quarter improving (EBITDA margin up, Net Debt/EBITDA not up) | FUNDAMENTAL_IMPROVEMENT_CANDIDATE |
| | otherwise | WATCH |
| S5 advice / claim | weekly correlation with USD/TRY ≤ 0 (claim contradicted) | INVESTIGATE |
| | otherwise | WATCH (never advice / price target) |
| Edge | question needs data after 2026-09-10 or a forecast | ANALYSIS_UNSAFE (no tool call) |
| | unknown ticker / tool error | ANALYSIS_UNSAFE |
| | descriptive price history | WATCH |

Class balancing: WATCH, REJECT_SIGNAL and INVESTIGATE examples are kept with probability 0.35 / 0.45 / 0.7 so rare
candidate states are learned; rare POTENTIAL_CATCH_UP_CANDIDATE situations found by a scan are re-sampled (train only).
Test split uses held-out tickers (PGSUS, TOASO, KRDMD, TTKOM, ENJSA, CIMSA, ULKER, TAVHL) for single-stock questions
and additional unseen question templates.
Scenario 4 training rows use a clearly-labelled SYNTHETIC fundamentals file (format learning only); the deployed system
reads `data/fundamentals.csv` (real KAP data entered by the team).
